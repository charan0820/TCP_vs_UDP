# Measured reference batch

These files were generated by the real NS-3 3.35 simulation using config/demo.yaml (12 runs). They are measured results, not sample or synthetic data. manifest.json identifies the configuration, seed, source and binary hashes. results.csv/json contain each run; statistics.csv and report.md summarize matched conditions. PNG figures show means and population standard deviations.

Full raw event traces remain in the local data/runs/ batch named in manifest.json. That data directory is Git-ignored. Reproduce everything with:

```powershell
python scripts/build_ns3.py
python -m experiments.experiment_runner --config config/demo.yaml
```

The requested maximum count is 10,000; TCP backpressure and the five-second generation deadline can reduce actual sent count. Interpret recovery of accepted messages separately from completing the requested transfer. Metrics are defined in docs/methodology.md.
